## 🚀 About Me

I am a versatile **Full-Stack & Mobile Engineer** with end-to-end expertise spanning frontend aesthetics, resilient databases, cross-platform mobile apps, and autonomous AI systems:

- 📱 **Mobile App Development**: Building production-ready cross-platform iOS & Android apps with **React Native**, **Expo SDK**, **NativeWind**, and **RevenueCat** in-app purchases.
- 🌐 **Modern Web & SaaS**: Architecting scalable web apps with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.
- 🎨 **UI / UX Design & Frontend Craft**: Designing clean, high-converting interfaces using **Figma**, **Framer Motion**, and craft-first typography with zero layout shifts.
- 🗄️ **Databases & Cloud Architecture**: Designing high-throughput data layers with **PostgreSQL**, **Supabase SSR**, **Drizzle ORM**, **Firebase**, and **Redis**.
- 🤖 **AI Automation & Agents**: Developing autonomous agent workflows, Model Context Protocol (**MCP**) integrations, **Vercel AI SDK** copilots, and **Computer Vision** models.
- ⚡ **Testing & Modern Tooling**: 100% type-safety, 40/40 **Playwright** E2E test suites, **Docker**, and automated **GitHub Actions CI/CD**.
- 📍 **Location**: India 🇮🇳 • Open for high-impact contracts, SaaS architecture, and product engineering.

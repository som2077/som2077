I am a product-focused **Full-Stack & Mobile Engineer** who bridges the gap between clean system architecture, fluid UI/UX design, and cutting-edge AI automation. 

- 📱 **Mobile Development**: Building native & cross-platform iOS/Android apps with **React Native**, **Expo SDK**, **NativeWind**, and **RevenueCat** subscription engines.
- 🌐 **Modern Web & SaaS**: Architecting resilient SaaS platforms with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.
- 🗄️ **Databases & Backend**: Designing high-throughput databases with **PostgreSQL**, **Supabase SSR**, **Drizzle ORM**, **Firebase**, and **Redis**.
- 🎨 **UI / UX Design**: Translating ideas into aesthetic, accessible, and responsive user experiences using **Figma**, **Framer Motion**, and craft-first typography.
- 🤖 **AI Automation & Agents**: Building LLM-driven applications, autonomous agents, Model Context Protocol (**MCP**) tools, and computer vision models.
- ⚡ **Testing & Tooling**: 100% type-safety, rigorous **Playwright** E2E test suites, **Docker**, and automated **GitHub Actions CI/CD**.
- 📍 **Location**: India 🇮🇳 • Open for high-impact contracts, product architecture, and tech collaborations.
